How-To · Host / president

Turn on Groups for the club

FARU Groups is a club/organization night board. Officers close gaps. Students still claim the ride.

The club is billed, not each student. Members still post seats, request rides, tap I’m here, and join a sober-ride network for free. A student can hold FARU+ at the same time.

FARU Groups vs Groups Pro

Groups ($9.99/mo) — event ride hubs, QR, club ride series, club-only listings.

Groups Pro ($24.99/mo) — everything in Groups plus officer roles, Command, I’m here (2 hours before arrive), check-out plans, still-out, waitlist, Driver on Duty, reminders, rain plan, advisor digest, campus packet, council, officer transition.

If the club is on neither plan, Club → Groups shows a Groups vs Pro comparison until you start IAP or redeem a code.

Start from Club → Groups

  1. Buy in the Play / App Store Host or president. Billed to the club account on that store.
  2. Or redeem a club code Owner can mint one code or a batch. Host/president redeems on Club → Groups. Extend or revoke stays with owner.

Campus license / Sponsored by

Owner can grant Groups or Groups Pro to every club at a university — including clubs that sign up later — with a Sponsored by name on Club → Groups. Club IAP still works; the higher tier wins.

That card shows membership through a date and who sponsored it. It does not auto-email the university. Student Affairs send from Command is a tap only if the license stored that inbox.

Name officers (Pro)

Assign president, event chair, ride chair, advisor. Transfer the gavel when the term ends. Advisor is read-only. Host keeps kick / ban / allow members to announce on the club itself.

Then run the night

Opening Groups does not dispatch rides. Your members still tap I have seats / I need a ride, then I’m here and Check-out plans. Officers close gaps on Command.

Book club, no plan yet

Groups tab shows the comparison. Redeem FG-TESTSEED-style code or start Groups IAP.

Campus-sponsored Pro

Every club at the school, including later signups, shows Through [date] · Sponsored by [name].

You also have FARU+

Plus is your student membership. Groups is the club’s. They stack; members without Plus still ride on the hub.
