How it works

  1. Apply Use your .edu email. Tell us how you’d get your first 25 students.
  2. Get accepted We review applications. Acceptance is not automatic — you’ll need a FARU account on that email.
  3. Share your code Your existing FARU referral code is your ambassador code. No second code.
  4. Earn in the challenge Rankings use credited referrals, then activity from students you brought in.

Apply

Pick an open campus challenge and submit. Applying is not acceptance.

Use the same .edu email as your FARU account so we can link your profile and referral code if you’re accepted.

Download FARU first

Accepted ambassadors need a FARU account. If you don’t have one yet, download the app, verify your school email, then apply with that same address.
